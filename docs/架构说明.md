# 代码结构

| 目录 | 职责 |
| --- | --- |
| `app/src/main/java/com/blueledger/app/app` | 主题、Compose 应用入口与导航 |
| `core/model`、`core/contract` | 账单、分类、账户、预算模型及仓库／备份接口 |
| `core/money`、`core/time` | 整数分金额、日期与周期计算 |
| `core/designsystem` | 颜色、图标、键盘、列表及公共控件 |
| `data/local` | Room 数据库、DAO、实体与显式迁移 |
| `data/repository` | 正式账本仓库与写入校验 |
| `feature` | 明细、记账、图表、管理、备份和相关页面 |
| `feature/advanced` | 分类预算、周期记账、标签、日历、月起始日与回收站 |
| `di` | 正式 Room 与系统时钟的依赖容器 |
| `demo` | 内存仓库和演示时钟，供开发及测试使用 |
| `app/src/test` | 业务、数据库、备份与 Robolectric Compose 测试 |
| `app/src/androidTest` | 需要设备或模拟器的仪器测试 |
| `app/schemas` | Room schema，供数据库迁移验证使用 |

正式应用由 `BlueLedgerApplication` 创建 `ProductionAppContainer`，使用文件型 Room 数据库和系统时钟。初始化默认分类、账户与设置，不写入示例账单。演示仓库不作为正式账本。

金额统一使用整数分，输入转换、统计与加减计算避免浮点误差。数据库更新通过仓库接口执行；迁移明确声明，不使用破坏性重建。备份先解析、校验和预览，再由用户确认恢复。

当前 Room 结构版本为 4，显式迁移为账户增加 location 字段，保留原账户、余额、账单和软删除记录，并按原名称与类型识别账户位置。JSON 备份 schema 4 包含账户位置、高级配置及独立回收站，并兼容 schema 1、2、3；恢复旧备份时缺失的高级配置按默认值初始化。标签关联、周期规则与分类预算的写入和恢复均经过引用及金额校验。

周期记账使用本地非精确闹钟，启动或返回应用时也补记。生成账单与推进规则日期在同一事务内执行；规则 ID 与日期组成稳定账单 ID，避免重复触发产生重复账单。自定义月起始日应用到统计周期，账单原发生日期与自然月日历保持不变。

页面在离开前台后停止明细与统计订阅，列表按批次加载。分类拖动结束后提交完整顺序，取消手势不写入。备份与 CSV 共用持久保存目录，系统授权失效时重新选择。

月报告图片通过应用自己的 FileProvider 分享；提醒由本地通知与广播接收器实现。Manifest 没有网络权限，开启提醒时请求通知权限。

品牌色、圆角、间距及界面尺寸集中于 `BlueLedgerTokens`。周图表保留全部七天横轴标签，日期按钮和历史周期前进按钮共用高度，避免切换时绘图区上下移动。预览测试会检查主页面比例、分类选中语义和打卡状态。

测试夹具与 README 预览只使用虚构记录。仓库不包含开发期间的真实账本、第三方产品截图、设备标识、签名密钥或本机 SDK 配置。


资产管家的平台分组由真实账户的 `AccountLocation` 派生，分组不拥有独立余额，不进入账户表，也不能成为收支账户。小荷包各自是可关联账单的独立账户。账户更新命令支持 `currentBalanceCent`：仓库在写事务中读取最新有效流水，反算期初基准并保存核对日期，避免编辑期间发生新账单导致余额失准；不写入收入或支出。普通账户管理不传此字段时，保留原期初余额行为，且未指定位置时保留已有 location。

页面通过公用组件组合呈现。`core/designsystem` 的折线、环形占比、排行、分段切换、年度导航、余额摘要、账户行、分组标题、导航行和下拉箭头只接受显示数据与回调，不访问仓库或做账本聚合。`LedgerFittedAmountText` 按真实文本测量适配金额宽度，兼容 Android 大字号的非线性缩放；既有 `LedgerAmountText` 保留收支符号及其调用契约。收支图表、资产图表、月报告与预算复用图表组件。

资产入口 `ReferenceAssetsRoute` 管理导航、详情和账户列表；统计组合在 `ReferenceAssetCharts.kt`，编辑及余额核对在 `ReferenceAssetForms.kt`。折线图缺失值使用 `null`，显示全年坐标但不伪造历史或未来余额。净资产环形图和排行的占比以资产与负债绝对值之和为分母，中心值和排行金额保留正负号。
